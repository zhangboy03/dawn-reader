# Comprehensible Input Lab

把“可理解输入”从一句学习建议，变成可以被使用、测量和证伪的语言学习产品实验。

## 核心判断

这个项目不从“如何让用户多背词、多刷题、多打卡”出发，而从一个更基础的问题出发：怎样让人持续获得**能理解、真有趣、数量足够**的目标语言内容？

三支罗肖尼视频给出的共同答案是：

1. 输入先于输出。流利表达主要是大量听读积累的下游结果，不应在材料不足时强迫输出。
2. 难度必须可理解。材料应略高于当前水平；听读只能理解零星内容时，应降低难度。
3. 兴趣不是奖励，而是持续输入的发动机。理想状态是注意力落在故事或知识上，暂时忘记自己在“学语言”。
4. 词汇不是“外语词 = 中文释义”的单点映射。真正掌握一个词，需要在多种语境中反复遇见它的词义、搭配、语域和语用。
5. 数量与重复不可替代。优先在同一作者、主题、系列中做窄域输入，让高价值词块自然复现。

这些是待验证的产品假设，不是不可质疑的教条。项目会区分视频作者的原始主张、我们的产品推论和实验结果。
