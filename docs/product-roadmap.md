# Dawn Reader 产品路线图

Dawn Reader 的目标不是复制一个通用电子书商城，而是做完整、可信的英文原著阅读闭环。排序依据是：先保证书不会丢、进度不会乱、帮助不会打断阅读，再扩展学习能力。

## P0 · 可以放心使用

- [x] EPUB 导入、分页阅读、主题与字号设置
- [x] 电脑端点击正文左右侧或使用左右方向键翻页
- [x] 网页与 iPad 多选/拖放 EPUB 导入、内容去重和明确可见的删除入口
- [x] 网页端与 iPad 原生端书架
- [x] 书架、进度和设置同步
- [x] 本地优先缓存与设备配对
- [x] 带确认的删除；远端失败时不先清空本地，离线旧设备不能让书“复活”
- [x] 词句选择、上下文释义、拆句与改写
- [x] 离线演示和真实 AI 结果明确区分
- [x] 公开首页、开源许可、贡献与安全说明

## P1 · 成为成熟阅读工具

- [ ] 书架排序、筛选、搜索、封面与自定义书单
- [ ] 目录、书内搜索、书签、划线、笔记和批量导出
- [ ] 内置词典与单词的多语境回看，而非孤立单词卡
- [ ] 同步冲突可视化、离线队列和删除恢复期
- [ ] VoiceOver、动态字体、键盘和 EPUB Accessibility 1.1 审计
- [ ] OPDS / Calibre 个人书库接入
- [ ] 可迁移的数据导入导出与自托管说明

## P2 · 验证学习是否真的发生

- [ ] 用“继续读了多久”和“卡点是否减少”衡量帮助，而不是只数点击
- [ ] 在相同作者、主题或系列中发现自然复现的词块
- [ ] 由用户选择是否回看真实遇到过的语境
- [ ] 为不同英文水平验证帮助密度，而不是把单一提示词当作真理
- [ ] 建立匿名、可退出的产品实验协议

## 明确不做

- 不提供盗版图书下载、付费绕过或仓库内置商业 EPUB；
- 不把整本原书预先翻译或改写成“简化版”；
- 不用连续打卡、排行榜和焦虑提醒替代阅读本身；
- 不把视频作者的观点包装成已证实的科学结论；
- 不在没有数据导出能力之前锁住用户的书和笔记。

成熟阅读器如 KOReader、Readium 生态和微信读书提供了功能参照，但 Dawn Reader 只借鉴完整性与可靠性，不复制其商业内容体系。
