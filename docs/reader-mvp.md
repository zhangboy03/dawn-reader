# Dawn Reader MVP：把难书调到“刚好能继续读”

## 打开以后，你会怎么用

这不是一个抽象的学习平台。每天早上六点，你打开它：

1. 第一次用，做一次约 3.5 分钟的真假词测试；系统只据此决定帮助是偏轻、平衡还是偏多。
2. 导入你已经决定要读、且合法持有的英文 EPUB/TXT/Markdown。
3. 正文始终显示原文。没有障碍就一直读，不弹词卡、不要求打卡、不强迫翻译。
4. 真正卡住时，选中一个词或一句话，在右侧请求短英文解释、温和改写或句子拆解。
5. 读完一段，反馈“顺畅 / 略有挑战 / 明显吃力”。它和实际求助记录会逐渐取代初始测试，成为更可靠的个人难度模型。

这就是当前架构：**一本本地书 + 一个阅读页 + 一个随叫随到的求助抽屉 + 一份逐渐变准的读者状态。**

## 为什么先做词汇校准，但不让它决定一切

首版使用 [LexTALE 官方测试](https://www.lextale.com/whatislextale.html)：63 次真假词判断，其中 3 项练习、60 项计分。官方给出的计分方式分别计算真词与伪词正确率后取平均，避免一味点击“是真词”获得虚高分数。项目使用官方固定顺序与 British spelling。

分档只采用原论文给出的粗略解释：低于 60 暂设为“约 B1 或以下”，60–79.9 为“约 B2”，80 及以上为“约 C1–C2”。论文明确提醒这不是正式 CEFR 认证，因此产品只把它当成首次打开时的辅助旋钮。

后续可增加两个可选深度测试：

- Vocabulary Size Test：估算整体词族规模；
- New Vocabulary Levels Test：定位在哪些频率层开始明显掉速。

它们来自 [Victoria University of Wellington 的 Paul Nation 词汇测试资源](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/vocabulary-tests)，更适合做研究校准，不适合挡在每天阅读之前。

## “i+1”在产品里如何实现

首版没有直接改写整本书。原因不是 AI 做不到，而是整本替换会丢失你想从英文原著得到的声音、修辞和思想细节，也会让人无法判断 AI 是否悄悄改了意思。

当前采用可逆的三层帮助：

1. **短释义**：只解释这个词在此处大概是什么意思；
2. **局部改写**：用更容易的英文重说选中部分，原句仍在左边；
3. **句子拆解**：找主干，再解释修饰与逻辑关系。

下一阶段再试验“章节伴读版”：AI 在原文旁生成可折叠的 B1/B2 版本，按段落对齐；用户可以随时回看原文，并标出删减的隐喻、语气或信息。是否值得保留，要看它能否同时提高晨读完成率、减少严重卡顿，又不降低对作者观点的理解。

## AI 与隐私

- 无模型：完整阅读流程照常运行；内置演示词条会标为 `offline-demo`。
- Ollama：本机服务启动且有模型时自动使用，原文片段不离开电脑。
- OpenAI API：仅在本机 `.env` 提供 key 时使用；浏览器端看不到 key。请注意 [ChatGPT 订阅与 API 账单彼此独立](https://help.openai.com/en/articles/8156019-is-api-usage-included-in-chatgpt-subscriptions-even-if-i-have-a-paid-chatgpt-account)。

书籍文件当前只由浏览器本地读取。只有用户主动选中的最多 1,200 个字符会进入求助请求。

## 关于《Zen and the Art of Motorcycle Maintenance》

项目没有从 Z-Library 下载或附带这本仍受版权保护的书。你可以购买出版社提供的电子版；例如 [Penguin 的官方页面](https://www.penguin.com.au/books/zen-and-the-art-of-motorcycle-maintenance-9781448114146)列出了 Kobo、Google Play、Apple Books、Amazon 等购买入口。取得合法 EPUB 后，直接使用“导入我的书”。

## 当前完成与下一轮验证

当前已经完成：

- LexTALE 完整答题、计分、粗分档与本地保存；
- EPUB/TXT/Markdown 本地导入；
- 桌面与手机宽度阅读界面；
- 选词/选句后的三种帮助；
- Ollama、OpenAI API 与明确离线降级；
- “认识 / 卡住”记录、会话计时和段落难度反馈。

下一轮不要先堆功能。先用你的真实书连续晨读 3–5 天，重点记录：

- 每次能连续读多久；
- 哪种求助最常让你重新进入正文；
- 一页平均需要几次求助；
- 原文是否仍是注意力中心；
- 哪些段落即使逐词理解仍然不懂。

这些数据会决定下一步是做章节级分级伴读、改进词组状态，还是只需要更好的句法拆解。
