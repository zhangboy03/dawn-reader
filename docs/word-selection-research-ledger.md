## Research conclusion

The user’s requested default is defensible for pointing gestures in a reading product, but it is not defensible as a universal Selection rule. Dawn should snap only active mouse/pen gestures, preserve a raw direction anchor, and keep keyboard and Alt/Option selection character-precise. Native Selection remains the semantic source for EPUB CFI and PDF quad capture. Warm `::selection` is the live paint; a CSS Custom Highlight (or an already-created renderer highlight) is required before the native pointing range is cleared.
